# 💀 Cursor Kill (v0.9 Pre-Alpha Stable)

**Cursor Kill** — это динамичный хардкорный Top-Down Action Survival рогалик, разработанный на движке **Solar2D (Lua)**. 

Проект создавался в одиночку на протяжении полугода. Финальный мега-патч версии 0.9 является завершающим для проекта.

## 🚀 Ключевые фичи и технологии
* **Продвинутый ИИ и Бестиарий:** 14 уникальных видов зомби (Призыватели, Лучники, Кислотные, Телепортеры, Призраки и Доноры с самонаводящимися снарядами). У каждого моба свой хитбокс, вес спавна и уникальное поведение.
* **Атмосфера и Визуал на лету:** Реализован динамический туман войны (Fog of War) с просчетом прямой видимости сквозь стены (Line of Sight), система темноты и освещения.
* **Сочный игровой фидбэк:** Динамическая камера, плавная анимация отдачи стволов, вылетающие гильзы, искры при попадании в стены, пульсация экрана и оверлеи при низком уровне здоровья (Low HP).
* **Криптография сохранений:** Защита данных игрока (`PlayerData.dat`) с помощью самописного алгоритма шифрования строк на базе побитового исключающего ИЛИ (`bxor`) со сдвигом сида (`seed`).
* **Интеграция с облаком:** Встроенная система сетевых запросов к внешнему API (JSONBin) с мастер-ключами для валидации и проверки актуальной версии игры при запуске.

## ⚙️ Системные требования и сборка
Игра разработана на движке **Solar2D (бывший Corona SDK)**. 
1. Склонируйте репозиторий.
2. Установите [Solar2D Simulator](https://solar2d.com).
3. Откройте файл `main.lua` через симулятор, чтобы запустить игру.

## 🎮 Управление (Взято из Туториала)
* **W, A, S, D / Стрелки** — Перемещение персонажа
* **L-SHIFT / R-SHIFT** — Ускорение (Бег)
* **L-CTRL / R-CTRL** — Приседание (Скрытность / Скорость восстановления энергии)
* **SPACE** — Рывок (Dash)
* **ЛКМ / ENTER** — Обычный огонь (Автоматический / Очередями)
* **ПКМ (Зажать)** — Прицеливание (Линия прицела становится зеленой)
* **R** — Перезарядка оружия
* **1 - 6** — Выбор оружия (Glock-17, AK-47 с переключением режимов, Benelli M4, Spas-12, Barrett M82, Plazmite)
* **V** — Использовать Аптечку
* **C** — Выпить Энергетик (Временный буст скорости, перезарядки и скорострельности)
* **G** — Бросить Гранату (Взрывается по таймеру, наносит урон по радиусу и ломает двери)
* **F** — Экстра-навык (Волна энергии со станом и отталкиванием / Просвещение, раскрывающее карту)
* **X** — Ультимейт (Невидимость / Фазирование сквозь стены)
* **E** — Взаимодействие (Открыть/закрыть парные двери, обыскать сундуки, зайти в лифт эвакуации, торговать с NPC Трейдером)
* **Q** — Смена режима огня для AK-47 (Одиночный / Очередь по 3 выстрела)
* **Z** — Быстрая смена экстра-способности
* **TAB** — Быстрая смена ультимейта
* **ESC** — Пауза (с интерактивным анимированным меню)
